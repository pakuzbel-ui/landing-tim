# TeamCash Premium Landing

Premium landing page на `Next.js + React + Tailwind CSS` для агентской команды, работающей с альтернативными платежными решениями в экосистеме MelBet.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Структура

- `app` — роуты, layout и глобальные стили
- `components/layout` — header и footer
- `components/sections` — секции landing page
- `components/ui` — переиспользуемые UI-компоненты
- `data/i18n.ts` — текстовые данные, переводы и массивы
- `lib` — утилиты
